\# 🏆 Real-Time Game Leaderboard App



A full-stack accessible leaderboard web app using:



\- 🔥 Frontend: \[Next.js (App Router)](https://nextjs.org/)

\- 🚀 Backend: \[FastAPI](https://fastapi.tiangolo.com/)

\- ⚡ Real-Time Storage: Redis (for leaderboard and caching)

\- 🗃️ Database: MongoDB (for persistence and history)

\- ♿ Accessibility: NVDA/JAWS support, skip links, keyboard shortcuts, ARIA live regions
